## 💡 QUÉ IMPORTA RECORDAR

### La Transformación Principal:
```
ANTES (Actual):
- Lectura + Ejercicios → 60+ min → Engagement bajo (65%)

DESPUÉS (Gamificado):
- Microbloques + Interactividad → 28-40 min → Engagement alto (92%)
- XP inmediato + Badges visuales → Motivación intrínseca
- Adaptativo según desempeño → No todos igual, ritmo personalizado
- Feedback psicológico → "Cree en ti" vs solo errores
```

### Mecánicas Principales (3):
1. **XP + Badges** = Progreso visible + logros tangibles
2. **Streaks + Multipliers** = Momentum & flow state
3. **Adaptive Difficulty** = Zona Goldilocks (desafío óptimo)

### Timing Realista:
- **MVP (Core):** 2-3 semanas

## 🎓 CONCEPTOS CLAVE

**Microlearning:** Aprender en bloques <5 min  
**Spaced Repetition:** Reforzar en intervalos (hoy, mañana, 3 días)  
**Adaptive Learning:** Dificultad según desempeño  
**Gamification:** Mecánicas de juego en educación  
**Intrinsic Motivation:** Recompensas psicológicas (badges, progress) vs calificaciones  
**Flow State:** Desafío óptimo = retención máxima  
**Streaks:** Racha de aciertos = momentum psicológico
